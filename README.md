# ⚡ Coin Escape (Unreal Engine Blueprint)

## Overview
A **third‑person coin collection game** built entirely with **Blueprints** in Unreal Engine 5.  
The player navigates narrow streets, collects coins, and avoids attacks from enemy AI wielding axes.  
This project was developed to **explore Blueprint scripting, node functionality, and animation/input control** without writing C++.

---

## 🎮 Gameplay
- Humanoid character movement through narrow streets  
- Coin collection system with overlap detection  
- Enemy AI attacks triggered when player passes nearby  
- HUD UI displaying values and feedback (health, coins)  

---

## 🔹 Blueprint Systems Explored
- 🎬 **Play Montage** – trigger animations at the right time  
- 🔄 **Do Once** – ensure actions only fire once  
- 🏃 **Launch Character** – apply velocity for dynamic movement  
- ✨ **Spawn Emitter Attached** – particle effects tied to gameplay events  
- 🔊 **Play Sound at Location** – immersive audio feedback  
- 🧠 **AI Move To** – enemy AI navigation and pursuit  
- 🎯 **Sphere Trace by Channel + Break Hit Result** – hit detection and combat logic  
- 📸 **Play World Camera Shake** – impactful feedback during attacks  
- 🏷️ **Actor Has Tag + On Component Begin Overlap** – event triggers and collision handling  
- ❌ **Destroy Actor** – clean removal of defeated enemies  
- ➕ **Add / Multiply Nodes** – value manipulation for gameplay logic  
- 🔄 **Make Rot From X + Get Forward Vector** – rotation and directional movement  

---

## 📊 Learning Outcomes
- Gained hands‑on experience with **Blueprint nodes** and their functionality  
- Learned how to control **animations, character inputs, and AI behavior** using Blueprints  
- Built a complete gameplay loop (movement, collection, combat, feedback) without C++  
- Strengthened understanding of **Unreal’s visual scripting workflow**
